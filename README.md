# 에이담 AI아카데미

독립 AI 교육기관 홈페이지의 프런트엔드입니다. 한국어 홈페이지에서 교육과정과 교육 방향을 확인할 수 있습니다.

## 로컬 실행

초기 검수 환경은 Node.js 24.20.0과 npm 11.19.0입니다. 프로젝트 루트에서 실행합니다.

```sh
npm ci
npm run dev
```

터미널에 표시되는 로컬 주소를 엽니다. 기본 주소는 http://localhost:3000 입니다.

## 검수

```sh
npx tsc --noEmit
npm run lint
npm run build
```

홈 화면은 `src/app/page.tsx`, 언어와 메타데이터는 `src/app/layout.tsx`, 공통 스타일은 `src/app/globals.css`에서 관리합니다.

## DAY 02 디자인과 브랜드 설정

기관명, 가칭 표시, 슬로건, 소개 문구, 로고와 대표 이미지 경로, 연락처는 `src/config/site.ts`에서 관리합니다. 미정인 대표 이미지와 연락처는 `null`로 둡니다. 시작 화면과 페이지 메타데이터는 이 설정을 읽습니다.

`src/app/globals.css`에 네이비·블루·틸 색상, 한글 시스템 서체, 4px 간격 단위, 제목 크기와 포커스 표시를 정의했습니다. 공통 버튼·카드·배지는 `src/components/ui`에 있습니다. 버튼은 기본적으로 `type="button"`이며, 비활성 상태는 HTML의 `disabled` 속성을 사용합니다.

## DAY 03 공통 레이아웃과 내비게이션

공통 헤더·본문·푸터는 루트 레이아웃에 있습니다. 메뉴 이름과 목적지는 `src/config/navigation.ts`에서 관리합니다. 기본 폭 1024px부터 상단 내비게이션을 표시하며 더 좁은 화면에서는 메뉴 버튼으로 여닫습니다. ‘교육정보’에서 공지사항·교육자료실·자주 묻는 질문으로 이동할 수 있습니다.

| 위치 | 현재 연결된 경로 |
| --- | --- |
| 헤더 로고 | 홈 `/` |
| 상단 메뉴 | 교육과정 `/programs`, 교육일정 `/schedule`, 교육성과 `/outcomes`, 교육협력 `/partnership` |
| 교육정보 하위 메뉴 | 공지사항 `/news`, 교육자료실 `/resources`, 자주 묻는 질문 `/faq` |
| 푸터 | 기관소개 `/about`, 문의 `/contact`, 펼쳐 읽는 개인정보처리 안내 초안 |

새로 연결한 9개 경로는 해당 작업일까지 준비 안내를 표시합니다. 예정된 강좌 상세 `/programs/[slug]`와 기수별 모의 신청 `/apply/[offeringId]`은 데이터가 준비되는 작업일에 연결합니다. 관리자 데모는 4주차에 `/admin/demo`를 기준으로 구성합니다. 하위 경로안은 강좌 `programs`, 일정 `offerings`, 가상 신청자 `applications`, 콘텐츠 `content`, 브랜드 `settings`입니다.

2026년 11월 6일 검수 결과 `npx tsc --noEmit`, `npm run lint`, `npm run build`가 통과했습니다. Edge의 360·768·1440px에서 모집중·마감임박·마감·예정, 같은 날짜에 있는 두 강좌, 달력·목록 전환, 연도 경계를 넘는 월 이동, 빈 달과 강좌 상세 연결을 확인했습니다. 서로 다른 시간대의 브라우저에서도 날짜와 요일이 일치했습니다.
