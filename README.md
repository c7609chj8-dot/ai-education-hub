# 에이담 AI아카데미

독립 AI 교육기관 홈페이지의 프런트엔드입니다. 한국어 홈페이지에서 교육과정과 교육 방향을 확인할 수 있습니다.

## 현재 배포와 인수인계

[Vercel 시연 사이트](https://ai-education-hub-ten.vercel.app)는 GitHub `main`과 연결되어 있습니다. 신청·문의·관리자는 실제 접수나 저장이 없는 시연이며, 관리자 시연에는 인증이 없습니다. [20일 작업 결과와 인수인계](docs/day20-handover.md)에서 화면 목록·검수 결과·남은 문제와 후속 Supabase 연계 계획을 확인할 수 있습니다.
## 로컬 실행

초기 검수 환경은 Node.js 24.20.0과 npm 11.19.0입니다. 프로젝트 루트에서 실행합니다.

```sh
npm ci
npm run dev
```

터미널에 표시되는 로컬 주소를 엽니다. 기본 주소는 http://localhost:3000 입니다.

## 검수

```sh
npx tsc --noEmit
npm run lint
npm run build
```

홈 화면은 `src/app/page.tsx`, 언어와 메타데이터는 `src/app/layout.tsx`, 공통 스타일은 `src/app/globals.css`에서 관리합니다.

## DAY 14 교육협력·문의·자료실

`/partnership`에서 기관별 교육협력 방향과 협의 과정 예시를 안내합니다. `/contact`의 문의 폼은 유형·가상 이름·가상 이메일·내용과 시연 안내 확인을 검사합니다. 입력이 유효하면 입력값을 지우고 실제 문의가 접수되지 않았음을 알립니다. `/resources`에는 자료 분류 예시와 파일 준비 중인 상태를 표시하며 다운로드 링크는 제공하지 않습니다.

2026년 11월 6일 검수 결과 `npx tsc --noEmit`, `npm run lint`, `npm run build`가 통과했습니다. Edge의 360·768·1440px에서 화면과 링크, 필수 항목·이메일 검사, 오류와 완료 후 초점, 재시연 초기화, 가로 넘침과 입력값 미전송을 확인했습니다. 자바스크립트가 꺼진 상태에서 입력값이 URL에 포함되지 않음도 확인했습니다.

## DAY 15 사용자 여정 통합 검수

교육협력 안내 화면이 추가된 현재 상태에 맞춰 공지와 FAQ의 예시 문구를 수정했습니다. 실제 협력 내용과 문의 방법은 여전히 확정 후 안내합니다.

2026년 11월 6일 Edge의 360·768·1440px에서 메인→강좌 검색·상세→해당 일정→신청 시연→FAQ→문의 시연의 흐름을 확인했습니다. 필수 입력 오류와 시연 완료, FAQ 키보드 조작, 모바일 메뉴의 Esc 닫기와 초점 복귀를 확인했습니다. 360px에서 공개 화면 20곳과 내부 이동 대상 22개, 이미지 로딩·대체 텍스트 속성, 폼 필드와 버튼의 이름, 제목 및 가로 넘침을 점검하고 잘못된 과정·기수 주소의 404를 확인했습니다. 수정한 공지·FAQ와 교육협력→문의 연결도 재검수했습니다. `npx tsc --noEmit`, `npm run lint`, `npm run build`가 통과했습니다.

## DAY 16 관리자 시연 대시보드와 강좌 목록

`/admin/demo`는 기존 예시 강좌·기수와 개인정보가 없는 가상 신청 항목을 사용해 현황과 목록을 보여줍니다. `/admin/demo/programs`는 같은 강좌 데이터의 읽기 전용 목록과 공개 과정 연결을 제공합니다. 두 화면은 로그인 없는 시연이며 실제 접수·저장을 하지 않는다는 안내를 표시합니다. 검색·편집과 일정·신청자 관리 화면은 후속 작업 범위입니다.

2026년 11월 7일 `npx tsc --noEmit`, `npm run lint`, `npm run build`가 통과했습니다. Edge의 360·768·1440px에서 현황 수치와 예시 안내, 두 관리자 화면 간 이동, 키보드 조작, 공개 강좌 연결, 가로 넘침과 브라우저 오류를 확인했습니다. 개발 서버는 연결된 기존 공개 강좌 상세 경로의 URL 매개변수 사전 렌더링 관련 개발 전용 경고를 출력했으며 해당 페이지는 HTTP 200으로 표시되었습니다.

## DAY 17 관리자 목록 검색·필터·편집 시연

`/admin/demo/programs`, `/admin/demo/offerings`, `/admin/demo/applications`에서 강좌·일정·가상 신청 목록을 검색하고 분야 또는 상태로 필터링할 수 있습니다. 편집 창에서 강좌명·소개, 일정 상태·장소, 가상 신청의 확인 상태를 바꿔볼 수 있습니다. 신청 예시에는 실제 개인정보를 사용하지 않습니다. 변경은 관리자 시연의 브라우저 메모리에서만 공유되며 공개 화면에는 반영되지 않고 시연 화면을 나가거나 새로고침하면 초기화됩니다.

2026년 11월 7일 `npx tsc --noEmit`, `npm run lint`, `npm run build`가 통과했습니다. Edge의 360·768·1440px에서 세 목록의 검색·필터·빈 결과, 강좌 입력 검사, 편집 적용·취소·Esc와 초점 복귀, 대시보드 간 상태 공유 및 새로고침 초기화를 확인했습니다. 관리자 시연을 벗어날 때의 초기화와 브라우저 저장소·수정 요청이 없는 점도 확인했습니다.

## DAY 18 브랜드 설정 시연과 접근성

`/admin/demo/settings`에서 기관명·슬로건·연락처 안내 문구를 편집하고 시연용 미리보기로 확인할 수 있습니다. 초기값은 확정된 브랜드 설정과 미정 연락처 안내입니다. 변경은 관리자 시연의 브라우저 메모리에서만 유지되며 공개 홈페이지에 반영되지 않고, 시연 화면을 나가거나 새로고침하면 초기화됩니다. 홈 이미지의 대체 텍스트에 AI 생성 예시를 명시하고 강좌 편집 오류 메시지를 해당 입력란과 연결했습니다.

2026년 11월 7일 `npx tsc --noEmit`, `npm run lint`, `npm run build`가 통과했습니다. Edge의 360·768·1440px에서 미리보기와 공개 화면 분리, 관리자 메뉴 이동, 초기화, 입력 레이블·초점·이미지 설명 및 가로 넘침을 확인했습니다. 자바스크립트가 꺼진 상태에서 폼 전송이 없음을 확인했습니다. 주요 색상 다섯 조합의 텍스트 대비는 5.17:1 이상이었고, 편집 오류 안내와 Esc 초점 복귀를 확인했습니다.
