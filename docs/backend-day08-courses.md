# 백엔드 8일차: 공개 강좌·커리큘럼 연결

작성일: 2026년 11월 7일

상태: **화면·공개 읽기 초안 및 격리 검증 완료 — 실제 개발 DB 공개 정책·예시 데이터 적용과 실제 API 검증 대기**.

## 현재 개발 DB

`ai-education-hub-dev`에는 강좌와 주차 데이터가 각각 0건이며, `academy` 스키마는 anon/authenticated의 사용과 조회가 차단되어 있습니다. 기존 `academy.courses`에는 교육 목표 필드가 없어 8일차 공개 데이터 초안에 필드 추가가 필요합니다. 기존 `public.rls_auto_enable()` 보안 경고 2건의 수정은 별도 작업으로 남아 있습니다.

이번 작업에서는 실제 DB 구조·권한·데이터를 변경하지 않았고 앞서 준비한 보안 마이그레이션 초안도 적용하지 않았습니다. 현재 공개 사이트는 기존 예시 데이터를 사용합니다.

## 준비한 변경

- 홈페이지 강좌 카드와 강좌 목록·상세는 서버 데이터 어댑터를 통해 예시 또는 Supabase 공개 뷰를 읽습니다. 기본값은 `mock`이며, `ACADEMY_COURSE_SOURCE=supabase`인 환경에서만 실제 공개 뷰를 요청합니다. 예상하지 못한 값과 조회 오류는 오류 화면으로 처리하고 예시로 조용히 대체하지 않습니다.
- 공개 데이터 모드에서는 설정·서버 오류와 없는 강좌를 구분하고, 없는 강좌는 404로 처리합니다. 주차 번호를 DB 값 그대로 표시하며, 실제 일정 연결 전에는 예시 일정으로 잘못 연결하지 않습니다.
- `ACADEMY_COURSE_DEMO_DATA`가 `false`가 아닌 경우 예시 교육과정 표시를 유지합니다. 개발용 예시를 사용할 때 이 표시를 제거하지 않습니다.
- `supabase/drafts/day08_public_courses.sql`은 공개된 강좌와 해당 주차에만 anon/authenticated가 읽을 수 있도록 RLS·열 권한과 `security_invoker` 공개 뷰를 구성하는 **검토용 초안**입니다. 교육 목표 필드를 추가하고 academy 스키마 사용 권한을 부여하므로 실제 적용 전 기존 객체와 향후 생성 객체의 권한을 함께 검토해야 합니다.
- `supabase/drafts/day08_dev_examples.sql`은 사용자가 선택한 기존 예시 5개 강좌·60주를 위한 **개발 전용 초안**입니다. 빈 테이블 검사와 트랜잭션 내 쓰기 잠금을 포함하며, 실제 데이터가 있는 환경에서는 중단합니다. 운영 데이터로 사용하지 않습니다.

## 검증과 남은 작업

`npm run test:course-access`는 일회용 메모리 PostgreSQL 17에서 예시 5개와 각 12주의 제목·교육 목표가 기존 자료와 일치하는지, 공개 역할이 비공개 강좌·주차와 쓰기 권한에 접근할 수 없는지, 비어 있지 않은 DB에서 예시 삽입을 거부하는지 검사합니다. 가상 공개 API와 격리 브라우저에서도 목록·상세·12주, 비공개/없는 주소 404, 빈 결과와 오류 시 예시 자동 대체 방지를 확인했습니다. 이는 실제 Supabase Data API 검증이 아닙니다.

실제 연결 전에는 개발 프로젝트 대상과 백업·기존 객체 및 역할별 권한을 재확인하고, 공개 정책·뷰·예시 데이터 변경의 적용 범위를 확정해야 합니다. 이후 개발 DB에만 적용하고 anon/authenticated의 공개·비공개·쓰기 차단을 실제 API로 검증해야 합니다. `public` Data API 노출 설정은 현재 미확인이며 로컬 설정으로 추정하지 않습니다. 적용 가능한 정식 마이그레이션과 원격 이력 버전도 일치시켜야 합니다.

기존 관리자 로그인·권한의 실제 계정 검증, 공개 보안 경고 2건, 관리자 역할 회수 방식과 운영 콘텐츠 확정은 별도 후속 작업입니다. 운영 DB와 `main`에는 반영하지 않았습니다.
