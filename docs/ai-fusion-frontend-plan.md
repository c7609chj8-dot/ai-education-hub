# 프론트엔드 우선 완성 계획

기준: PR #37 `codex/ai-fusion-branding`, 2026-11-11. 실제 DB 적용은 계속 보류한다.

## 분석

- 브랜드·6개 학과·72주차 초안·시연 ID 분리가 구현되어 있다. 기존 5개 과정 상세 및 시연 주소도 보존되어 있다.
- 메인은 단색 배경, 상세는 대표 이미지 없이 긴 본문 뒤에 일정 버튼이 있다. 카드의 ‘완성 결과물’은 초안의 확정 결과로 오인할 수 있다.
- 일정/신청의 시연 안내, 키보드 메뉴, 사진 수동 전환 및 reduced-motion 처리는 유지할 가치가 있다.
- 공통 제목 영역·입력 상태를 정리하고 공유 메타데이터를 보완한다. 관리자·데이터 서비스·SQL은 수정하지 않는다.

## 실행 순서와 완료 기준

1. 히어로, 공통 제목·카드·버튼·푸터 스타일을 통일한다. 제공 로고 원본 비율을 유지한다.
2. 상세 대표 이미지·바로가기·주차별 과제 구분을 추가한다. 12주·교육시간·일정의 미확정 상태는 유지한다.
3. 일정 선택 결과 알림과 시연 폼 오류·모바일 입력 안내를 개선한다. 입력 전송·저장은 추가하지 않는다.
4. 공유 이미지·OG/Twitter 메타데이터, 기존 파비콘을 확인한다.
5. TypeScript, ESLint, Webpack 빌드, 데이터/HTTP 회귀 검사 후 1440·768·390·360px 시각 검수를 진행한다.
6. 기존 PR #37에만 반영하고 Vercel Preview를 검수한다. main 병합·Production 배포는 하지 않는다.

## 환경별 기대값

- 시연 Preview: 고유 시연 ID를 사용하는 6개 학과·72주차 초안. 실제 신청 저장 없음.
- Supabase Preview: DB의 공개 강좌 5개·60주차가 표시되는 것이 현재 정상이다. 비공개 시험 기수는 공개되지 않는다. 신규 학과를 억지로 혼합하지 않는다.
- 실제 DB 백업 및 복구 검증 → 새 preflight → 승인 범위 A1/A2 비공개 등록 → 별도 공개 API/상태 전환 승인 순서로 추후 진행한다.

완료 결과·제약·화면별 증거는 별도 검수 보고서에 기록한다.
