# B-03-6 시험 데이터 정리 판정과 B-03-7 검수 계획

점검일: 2026-11-10 (Asia/Seoul)

## B-03-6 현재 판정

**등록·장소 수정은 실증 완료, 삭제와 최종 종료는 보류.** 사용자는 승인된 삭제 경로가 없으면 중단하도록 조건을 걸었다. 읽기 전용 점검에서 관리자용 삭제 경로가 확인되지 않아 DB 쓰기는 수행하지 않았다.

| 점검 항목 | 확인 결과 |
| --- | --- |
| 대상 | 개발 프로젝트 `uenvjqgylrevujdjpfed`의 시험 UUID `e9791c02-5bbf-4b55-86e3-7b6302cd6711` 1건. 기존 시험 강좌에 연결돼 있고 장소는 `B-03-6 개발 시험 (수정)`, 비공개 draft |
| 데이터 | 강좌 5개, 주차 60건, 기수 1건, Auth 사용자 2명, 관리자 1명 |
| 참조 | `academy.offerings`를 참조하는 외래키 0건. 조회한 비시스템 테이블에 `offering`·`cohort`가 포함된 열이나 application·payment·attendance·enrollment가 포함된 테이블 이름은 없었다. 외부 시스템이나 다른 이름의 논리적 참조까지 없다는 뜻은 아니다 |
| 삭제 경로 | 조사한 앱과 함수에 관리자용 삭제 API/RPC가 없으며 v2는 조회·등록·수정만 제공한다. anon·authenticated·service_role은 `academy.offerings` DELETE 권한이 없다. postgres는 DELETE와 BYPASSRLS를 갖지만 해당 고권한을 이용한 직접 삭제는 이번 조건에 맞지 않는다 |
| 백업 | 현재 확인된 최신 기존 백업 4개 파일의 SHA-256이 일치했다. 시험 기수 등록 전의 백업으로 강좌 5·주차 60·기수 0·Auth 2·관리자 1 기준이다. 현재 시험 기수 자체는 포함하지 않으며 이 백업의 실제 복원과 Supabase Auth 전체 복원은 미검증 |
| 공개 API | 현재 익명 Data API에서 강좌 5개·주차 60개·공개 기수 0건, 대상 UUID 0건을 모두 HTTP 200으로 확인 |
| 관리자·일반 사용자 | Auth 2명·관리자 1명과 DB 권한을 확인. 직전 작업의 실제 관리자 수정은 성공했으나 이번에는 실제 일반 사용자 JWT 거부와 관리자 로그인을 재시험하지 않았다 |

이전 개발 DB 등록·장소 수정과 격리 테스트의 근거는 [B-03-6 검증 기록](backend-b03-6-offering-verification.md)을 따른다. 이번에 삭제하지 않았으므로 삭제 후 검증(대상 UUID 0건·전체 기수 0건 등)은 **미실시**다.

### 정리 재개를 위한 검토

사용자가 지정한 '삭제 경로가 없으면 중단'과 'RLS 우회 금지'에 따라 고권한 DB 직접 삭제나 권한 추가를 실행하지 않는다. 향후 별도 요청이 있으면 개발용·비공개 draft·지정 UUID·참조 없음으로 대상을 제한하는 방식과 인증·권한·감사, 동시 변경 시 충돌, 실패 시 롤백을 비교한다. 실제 DB 변경 전 SQL, 변경 객체, 격리 테스트와 별도 승인을 준비한다. 승인된 경로가 실제 존재하는지 확인하고 대상과 참조를 다시 점검한 뒤에만 삭제를 검토한다.

## 별도 이슈: 일시적 HTTP 500

2026-11-09 로컬 개발 서버에서 관리자 화면 GET 1건이 `SyntaxError: Unexpected end of JSON input`과 HTTP 500을 반환했고 이후 GET은 HTTP 200이었다. 발생 위치의 상세 스택과 재현 조건이 보존되지 않아 원인은 특정하지 못했다. 관련 앱 코드에서 직접 JSON 파싱 호출은 찾지 못했지만 프레임워크·라이브러리·환경 원인까지 배제할 수 없다. 2026-11-10 목록 GET·장소 수정 POST·재조회 GET은 HTTP 200으로 재발하지 않았다. **원인 미확정이며 해결됐다고 볼 수 없다.**

다음 검수에서는 실데이터를 쓰지 않는 격리 환경에서 개발 서버 최초 실행·새로고침·수정 직후와 프로덕션 빌드를 비교하고, 비밀정보와 개인정보를 제거한 오류 스택과 응답 상태를 기록한다. 재현되면 최소 수정과 회귀 검사를 수행하고 재현되지 않으면 미해결로 유지한다.
