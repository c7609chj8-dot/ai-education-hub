# AI융합대학 프론트엔드 사전 공개 계획

## 기준과 목적

- 기준 커밋: `main`의 `a33a0125c6572e8d0141ee16946b607ebc594067`
- 작업 브랜치: `codex/ai-fusion-frontend-prerelease`
- 목적: 기존 Vercel 프로젝트에서 안전하게 검토할 수 있는, 정적·mock 데이터 전용 공개 화면을 준비한다.
- 이 브랜치는 실제 수강신청, 관리자 운영, Supabase 읽기·쓰기 또는 개인정보 수집을 포함하지 않는다.

## 공개 범위

- AI융합대학 이름과 슬로건: “AI로 연결하는 지식, 융합으로 여는 미래”
- 두 개의 공식 이미지 로고
- AI 경영관리·음악제작·항공영상제작·멀티미디어·프로그래밍·광고영상제작 6개 학과
- 각 학과의 12주차 교육과정 초안(총 72주차)
- 정적 대학소개, 교육성과 예시, 공지 예시, FAQ, 교육협력 안내
- PC·모바일 반응형 공용 레이아웃

모든 학과·결과물·교육과정 화면에는 검토용 초안임을 표시한다. 교육시간, 실제 교육기수, 모집 일정, 정원, 강사, 학위·자격 정보는 표시하지 않는다.

## 제외·차단 범위

- #35의 관리자 API, Supabase 연동, RPC, RLS, 마이그레이션과 운영 스크립트
- #36의 B-04 신청 저장 설계와 실제 접수 기능
- #37의 관리자·API·DB·환경변수 관련 변경
- 실제 또는 예시 교육기수, 모집 상태, 정원, 잔여석, 수강신청 입력 폼, 문의 입력 폼

`src/proxy.ts`는 `ACADEMY_PUBLIC_RELEASE_MODE`가 `backend`가 아닌 경우(기본값) `/admin/:path*`와 `/api/:path*`를 서버에서 `404`로 반환한다. 즉, 메뉴를 숨기는 것과 별개로 기존 관리자 데모와 이후 추가될 API 경로를 URL로도 접근할 수 없다. 향후 백엔드 정식 공개는 별도 보안 검토와 승인 뒤에만 서버 전용 환경변수 `ACADEMY_PUBLIC_RELEASE_MODE=backend`를 명시해 진행한다. 이 브랜치에서는 해당 환경변수를 만들거나 설정하지 않는다.

## Production 영향과 배포 전 확인

- 이 브랜치가 병합되기 전에는 기존 `main`, Vercel Production, 도메인, 환경변수, Supabase 데이터에 영향이 없다.
- 병합 후에도 기본값은 공개 프론트엔드 전용 모드이므로 관리자·API 경로가 차단된다.
- Vercel 환경변수 값을 읽거나 복사하지 않으며, 공개 화면에는 Supabase 클라이언트 의존성을 추가하지 않는다.
- 모든 응답에는 `nosniff`, `DENY` frame, referrer, permissions 정책 헤더를 추가한다.
- 사전 공개 단계에서는 검색 색인 방지 메타데이터를 사용한다. 정식 공개 전 SEO 정책은 별도 승인 대상으로 둔다.

## 검증 순서

1. `npm run test:public-prerelease`로 6개 학과·72주차, 빈 기수 데이터, 서버 차단, 공개 입력 폼 부재를 확인한다.
2. TypeScript, ESLint, Webpack build를 실행한다.
3. 로컬 서버에서 공개 라우트와 `/admin`, `/api`의 HTTP 응답·헤더를 확인한다.
4. Draft PR의 Vercel Preview에서 PC·모바일 레이아웃, 로고, 메뉴, 학과 상세, 준비 중 안내를 검수한다.
5. 기존 Vercel 프로젝트의 Production 도메인·보호 설정을 읽기 전용으로 재확인한다.

`main` 병합, Production 배포·보호 설정 변경, Supabase 변경, A1·A2 실행은 별도 최종 승인 전까지 수행하지 않는다.
